# cat_labirinth
AI Maze Navigation Simulation (Unity &amp; Reinforcement Learning)

Developed in collaboration with Sándor Almási, we created a machine learning simulation in Unity where an AI-controlled agent (a cat) learns to navigate through a maze to find a specific target (a fish). We utilized Reinforcement Learning principles to design the training environment, establish the reward and penalty system, and train the agent to optimize its pathfinding behavior over multiple iterations. This project allowed us to combine our Unity programming skills with our interest in Artificial Intelligence.
